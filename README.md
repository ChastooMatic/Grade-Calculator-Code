# 🎓 Academic Performance Evaluator

A Python-based academic utility designed to evaluate and calculate student grades efficiently. Developed as part of the Programming Fundamentals and Logic Building Using Python curriculum in association with IBM.

## 📑 Project Overview
This command-line application takes a student's marks across five subjects, computes the total aggregate and percentage, and assigns a final grade based on standard academic thresholds. 

## ✨ Key Features
* **Automated Calculations:** Instantly computes totals and percentages.
* **Grade Assessment:** Accurately assigns grades (A, B, C, D, F) based on a 40% passing threshold.
* **Robust Input Validation:** Ensures all entered marks are strictly within the 0-100 range, preventing application crashes from invalid data.
* **Batch Processing:** Utilises iterative loops to process multiple student records in a single session.

## 💻 System Requirements
* Python 3.x
* A standard terminal or command prompt

## 🚀 How to Run
1. Clone this repository or download the `main.py` file.
2. Open your terminal or command prompt and navigate to the folder containing the file.
3. Execute the script using the following command:
   ```bash
   python main.py
   ```
